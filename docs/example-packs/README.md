# Example packs (docs / templates)

Markdown **templates** for specialist agent setups. They are not a marketplace,
plugin SDK, or installable package registry.

Copy a pack into a project as `<cwd>/.spockify/skills/<id>/SKILL.md` (or keep
notes under `.spockify/`) and attach with the CLI/IDE skill tools when useful.
Default attach stays ≤2 skills.

| Pack | Path | Focus |
|------|------|--------|
| Python backend | [`python-backend.md`](python-backend.md) | API, Postgres, tests, security review, docs, CI |
| React frontend | [`react-frontend.md`](react-frontend.md) | UI, a11y, performance, browser checks, design system |

These mirror the Strategic Roadmap Phase 6 “example packs” idea as **documentation
only**. Shipping a public pack marketplace is a later Priority 5 item.
