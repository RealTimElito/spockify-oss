Self-hosted coding stack for open-weight models. One kernel. Your GPUs.

Chat, IDE, and CLI on LiteLLM. Default harness is Spockify. Wichy-class tool loops and OpenHands-class SWE sandboxes are optional backends — not the product.

Self-host Download IDE Sign in

Wichy is a local tool framework. OpenHands is a SWE sandbox. Spockify is the environment both can plug into — default loop included.

Three pools

  • Chat — UI and router. No SWE on this ingress.
  • Coding sessions — One runHarness process per session.
  • Eval — Canary and slices. Never the chat ingress.

More GPUs add sessions. They do not raise pass@1. Quality is model × harness × slice.
